# العميل (Thronefall Mobile Client)

واجهة اللعبة — TypeScript + Vite + three.js. **شاشة عرض وإرسال أوامر فقط** (راجع `docs/GAME_DESIGN.md` §5.2): مفيش أي منطق لعبة هنا، ومفيش قائمة محتوى مخزّنة. كل رقم بيتعرض جه من السيرفر، وكل زرار بيبعت **نية** والسيرفر هو اللي بيحسم.

## التشغيل

محتاج السيرفر شغال الأول:

```bash
dotnet run --project server/Thronefall.Api     # على :5246
npm --prefix client install
npm --prefix client run dev                    # على :5173
```

بعدها افتح `http://localhost:5173`. باراميترات مفيدة للتجريب:

| الباراميتر | المعنى |
|---|---|
| `?opponent=atk\|eco\|def` | استراتيجية البوت الخصم |
| `?speed=N` | يضغط N ثانية محاكاة في ثانية حقيقية (تطوير فقط) |

مثال: `http://localhost:5173/?opponent=def&speed=20`

## البنية

| الملف | الغرض |
|---|---|
| `src/protocol.ts` | عقد السلك كامل + `MatchConnection`. مطابق لـ`server/Thronefall.Engine/MatchSnapshot.cs`. **مفيش حسابات لعبة.** |
| `src/hud.ts` | الواجهة: الموارد، المؤقّت، أشرطة HP، أزرار البناء/التدريب (مبنية من كتالوج السيرفر)، أزرار الغضب. |
| `src/scene.ts` | مشهد three.js — كل مجسّم بيعكس قيمة جاية من السيرفر. **placeholder فني**. |
| `src/main.ts` | التوصيل: يفتح الاتصال، يوزّع الحالة على الـHUD والمشهد. |
| `vite.config.ts` | proxy لـ`/ws` عشان الاتصال same-origin في التطوير والإنتاج بنفس الكود. |
| `e2e/smoke.mjs` | فحص end-to-end في متصفح حقيقي بمقاس موبايل. |

## الاختبار

```bash
npm --prefix client run build     # TypeScript strict + حزم الإنتاج

# فحص حقيقي: متصفح فعلي، مقاس موبايل، مباراة كاملة، صفر أخطاء console
# (محتاج playwright مثبّت محلياً أو عالمياً، والسيرفر + dev server شغالين)
node client/e2e/smoke.mjs --speed 20 --shots ./shots
```

الفحص ده بيتأكد من:
- كتالوج السيرفر اترسم فعلاً (لو الأزرار فاضية يبقى الـhandshake فشل بصمت).
- مباراة كاملة اتلعبت واتحسمت بأوامر حقيقية.
- **عميل متلاعب فيه**: بيفعّل زرار معطّل ويضغطه — لازم السيرفر يرفض. تعطيل الأزرار في الواجهة **شكلي**، السلطة في السيرفر.
- صفر أخطاء console.

## ⚠️ الحالة الفنية

المشهد حالياً **مكعبات ومستطيلات**، والـHUD تنسيق وظيفي بسيط. الطابع الكرتوني المستوحى من Clash Royale هو الخطوة الجاية (`docs/PROGRESS.md`). منطق الربط بالحالة في `scene.ts` هو اللي هيفضل بعد استبدال المجسّمات — الأشكال نفسها هي اللي هتتغير.
